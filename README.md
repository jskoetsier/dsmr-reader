# DSMR-reader
*DSMR-protocol reader, telegram data storage and energy consumption visualizer. 
Designed for reading the smart meter DSMR (Dutch Smart Meter Requirements) P1 port at your home. 
Requires a cable and hardware capable of running Linux software. 
**Free for non-commercial use**.*

## Features

DSMR-reader provides:
- Real-time energy consumption monitoring
- Historical data analysis and visualization
- Cost tracking and estimation
- Multiple dashboard views and customizable graphs
- API for integration with other systems
- MQTT support for home automation integration
- Backup and data export capabilities
